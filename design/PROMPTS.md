# Porchlight design prompts

Run each complete prompt below in Gemini or Canva to make one mobile app mockup. Save the five resulting PNGs with these exact names in this directory:

| Screen | Filename |
|---|---|
| Map home | `design/01-map-home.png` |
| Muse nudge sheet | `design/02-nudge-sheet.png` |
| Message composer | `design/03-composer.png` |
| Voice post | `design/04-voice-post.png` |
| Invite detail | `design/05-invite-detail.png` |

Each prompt includes the same style kernel so it can be copied on its own. Use fictional neighbors and no real photos of people. The frontend will use these mockups as visual references; the text and controls named here should stay legible.

## 1. Map home → `design/01-map-home.png`

```text
Mobile app UI mockup, iPhone frame, for "Porchlight", a neighborhood connection app.
Mood: warm, calm, dusk — the feeling of porch lights coming on. Not corporate, not
playful-cartoon. Palette: deep dusk navy background (#1B2333), warm amber accent
(#F5A623) for connections and calls to action, soft cream text (#F7F1E3), muted sage
(#8FB39A) for "free" statuses, dim slate (#4A5568) for unreached areas. Rounded cards
(16px radius), generous spacing, one clear primary action per screen. Typeface: a
friendly humanist sans (e.g., Nunito or Inter). Map uses a dark, low-contrast street
basemap so amber connection lines glow. Emoji avatars in circles. No real photos of
people.

Design the Map home screen. Show a dark map of a neighborhood with amber lines from
"You" to about six fictional neighbors, using varied line thickness. Shade one street
in slate and label it "Duval St · 0 met". Add amber invite pins and sage "free" status
pins. Put a community toggle in the top bar reading "Hyde Park | Quarry Lofts" and a
Reach chip reading "You've met 6 of 40". Add a floating microphone button at the
bottom right. Keep the map readable and the gap on Duval St immediately visible.
```
